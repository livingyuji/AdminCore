AdminCore — Installation & Setup Guide

Author & Developer: LivingYuji
Target Environment: Minecraft Paper 1.21.1+ | Java 21+
Notice: AdminCore is an original Minecraft plugin developed by LivingYuji. All original AdminCore source code, project documentation, and project-specific assets created for this project are credited to LivingYuji.

1. System Requirements

Component Requirement Notes
Java Runtime Java 21 (LTS) Eclipse Adoptium Temurin 21 recommended
Server Platform Paper 1.21.1 Supports modern Adventure components
Storage Engine SQLite Embedded, automatic schema migrations
Optional Plugins Vault, LuckPerms Gracefully detected if present

2. Installation Instructions

  1. Verify Java 21 is installed: java -version
  2. Cleanly stop your Minecraft server with stop.
  3. Copy AdminCore-1.0.0.jar into the server plugins/ folder.
  4. Start the server. Configuration files and database will be generated automatically in plugins/AdminCore/.
  5. Verify startup by reviewing server console logs.

3. LuckPerms Permissions Configuration

Configure staff roles using LuckPerms:

# Helper Role
lp group helper permission set admincore.gui true
lp group helper permission set admincore.player.info true
lp group helper permission set admincore.player.freeze true
lp group helper permission set admincore.moderation.warn true

# Moderator Role
lp group mod permission set admincore.gui true
lp group mod permission set admincore.player.* true
lp group mod permission set admincore.moderation.* true
lp group mod permission set admincore.player.staffmode true

# Administrator Role
lp group admin permission set admincore.* true

4. Quick Start Commands

  • /ac — Open the interactive 10-section Admin Control Center
  • /ac help — View category-specific help pages
  • /ac reload — Safely reload all configuration files
  • /ac version — View version and author credits
